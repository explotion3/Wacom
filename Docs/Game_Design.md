## §1 游戏概述

本项目是一款**单人第一人称 HD-2D 卡牌冒险游戏**。

玩家选择一个角色进入可探索区域，遭遇敌人、收集卡牌、调整背包，通过一场场高风险的部位制卡牌战斗推进 Run。

### 核心卖点

- **第一人称 HD-2D 表现**：玩家以第一人称面对敌人，敌人以多部位 HD-2D 角色呈现在画面前方。
- **部位制敌人**：敌人由头、身体、尾巴等多个部位组成，每个部位有自己的生命、意图和先机。
- **Cost 风险模型**：卡牌 `Cost` 不消耗玩家资源，而是扣减所有敌方存活部位的先机，可能提前触发敌人行动。
- **空间手牌**：手牌被左手牌、右手牌切成左手区、双手区、右手区，不同区域改变卡牌价值。
- **背包构筑**：战斗外背包保存永久卡牌池，玩家在战斗前从背包中选择卡牌组成战斗卡组。

### 目标体验

玩家每一回合都应面对清晰但有压力的选择：

- 高 Cost 牌能获得强效果，但可能让多个敌人部位立刻行动。
- 低 Cost 牌更安全，但可能错过完美释放或关键击破窗口。
- 同一张牌处在不同手牌区域时，价值可能完全不同。
- 打出左手牌或右手牌会改变整个手牌结构，带来短期收益和区域失效风险。
- 击破敌人关键部位可以改变战斗节奏，但敌人并不一定立刻死亡。

游戏应让玩家感觉自己在"观察敌人动作、调整手牌位置、抓住释放时机"，而不是按费用曲线打牌。

### 游戏循环

**Run 循环**：

```
进入区域 → 探索 → 遭遇战斗/事件/商店/休息 → 获得或调整卡牌 → 继续探索 → 挑战区域 Boss → 进入下一区域或结束 Run
```

**战斗循环**：

```
战斗开始 → 初始化玩家生命、战斗卡组、敌人部位 → 玩家回合开始抽牌
→ 玩家执行回合操作：打牌/等待/结束回合
→ 敌人部位可能因先机归零在玩家回合内行动
→ 玩家主动结束回合 → 存活部位按顺序行动 → 进入下一回合
→ 全部部位破坏后胜利 / 玩家生命归零后失败
```

## §2 核心玩法

### Cost 风险模型

- 卡牌 `Cost` 表示打出该牌后减少敌方所有存活部位的当前先机值。
- `Cost` 不消耗玩家 AP / EP。
- 战斗中可以出现 `Runtime Cost` 修正，完美释放判断和先机扣减都使用当前 `Runtime Cost`。
- 例如某牌基础 `Cost = 3`，被降到 `Runtime Cost = 2`，则按 2 判断完美释放，也按 2 扣减敌方部位先机。

### 费用转移

- 一张卡的 Cost 可以被临时降低，降低值可以转移到另一张卡上。
- 当前战斗内生效，可叠加。
- 示例：被腾挪卡 `Cost = 3`，被降低 1 点 Cost；这 1 点转移给朝光暮蝶，使朝光暮蝶 `Cost 0 → 1`。

### 费用合法性

```
Enemy Initiative Sum = Sum(Living Enemy Parts CurrentInitiative)
if CardRuntimeCost > Enemy Initiative Sum → 卡牌不可用
```

### 手牌空间

手牌不是普通线性列表，而是由左手牌和右手牌切分出的空间结构：

```
[左手区] [左手牌] [双手区] [右手牌] [右手区]
```

不同区域会改变卡牌价值（区域效果）。腾挪操作让玩家通过调整手牌空间来制造区域效果、完美释放机会和 Cost 转移。

### 部位制敌人

敌人由多个部位组成，每个部位近似一个独立战斗单元。部位 HP 归零后进入破坏态，全部部位破坏后战斗胜利。

### 完美释放

如果打出的卡牌 `Runtime Cost` 正好等于某个敌方部位在出牌前的当前先机，则该部位触发完美释放效果。多个部位可同时命中。迅捷卡不触发完美释放。

完美释放应当成为玩家主动规划的关键收益，而不是偶然出现的小加成。

### 等待

等待是不消耗手牌的节奏调节手段：

- 所有敌人部位当前先机减少当前等待值。
- 等待结算后，当前等待值 +1。
- 每回合开始时等待值重置为 2。
- 等待不触发完美释放。

## §3 玩家

玩家拥有：

- 当前生命值 / 生命值上限
- 战斗卡组（抽牌堆、手牌、弃牌堆、消耗区）
- 战斗外背包
- 左手牌和右手牌

### 手与手指

- 玩家角色默认拥有左手牌和右手牌，以及 10 个手指。
- 手指是通用身体资源，影响玩家最大生命值。失去手指 = 失去最大生命值。
- 每次失去手指时，左手牌或右手牌会发生相应卡面变化。
- 失去 5 个手指后，玩家会失去一张左右手牌（先失去哪张暂定）。
- 手指系统影响角色生命、左右手牌、手牌区域结构和部分角色专属任务。

### 左手牌与右手牌

- 左手牌 / 右手牌是每个角色初始自带的核心牌。
- 不同角色的左手牌 / 右手牌可以有不同效果和 Cost。
- 它们本身是普通卡牌，可以被打出、被删除。
- 打出后离开手牌，不进入任何卡牌区域（进入 Limbo）。
- 回合开始时强制抽回。
- 自带保留效果。
- 如果被永久删除，对应区域永久消失，双手区也不存在。

## §4 卡牌设计

### 基础属性

卡牌至少包含：

| 属性 | 说明 |
|---|---|
| 名称 | 显示名 |
| Cost | 打出后扣减敌方先机的值 |
| 身材（可选）| 入战属性（生命值上限、耐久、容量等）|
| 类型/词条 | 关键词标签 |
| 稀有度 | 白/蓝/固有 |
| 效果 | 主动效果列表 |
| 被动（可选）| 不需要主动打出也能响应事件的效果 |
| 区域效果（可选）| 根据所在区域触发的额外效果 |
| 完美释放效果（可选）| 命中完美释放时的额外效果 |

### 关键词

| 关键词 | 说明 |
|---|---|
| 迅捷 | 打出时不减少敌方部位先机，不触发完美释放 |
| 伙伴 | 卡牌词条，不作为场上实体被攻击 |
| 连击 | 使用后可重复使用，打出后留在原位置 |
| 保留 | 回合结束时不弃掉 |
| 武器 | 卡牌词条 |
| 工具 | 卡牌词条 |
| 突袭 | 暂未定义 |

### 已确认卡牌规则

#### 朝光暮蝶

- `Cost = 0`，身材：1 生命值上限，词条：伙伴，稀有度：白
- 入战时角色生命值上限 +1，当前生命值 +1
- 随机腾挪 1 张我方卡牌（范围：当前手牌）
- 施加等于此卡当前 RuntimeCost 的中毒（目标：指定敌方部位）
- **左手区 + 完美释放**：本次打出不减少敌方部位先机（不作为真正"迅捷"关键词）
- **右手区**：通过此卡腾挪的卡牌 Cost -1，减少的 1 点转移到朝光暮蝶上（可叠加）

#### 拂晓飞蛾

- `Cost = 0`，身材：1 生命值上限，词条：伙伴，稀有度：蓝
- 入战时角色生命值上限 +1，当前生命值 +1
- 对一个敌方部位施加 1 减速
- **被动**：每当你在本场战斗内打出三张伙伴牌时，使此牌从所有非手牌区域回到手牌
  - "三张伙伴"是战斗内全局计数，触发后计数清零

#### 赤腹工蚁

- `Cost = 0`，身材：1 生命值上限，词条：伙伴/保留，稀有度：白
- 入战时角色生命值上限 +1，当前生命值 +1
- 将双手区域的随机 1 张卡牌腾挪至其他区域（排除双手区，目标为左手区或右手区）
- 如果双手区不存在，则此牌不能打出

#### 烁光蝶

- `Cost = 1`，身材：6 生命值上限，词条：伙伴/武器/连击，稀有度：白
- 入战时角色生命值上限 +6，当前生命值 +6
- 造成 7 伤害（目标：当前选中的敌方部位）
- **连击**：使用后可重复使用
- **被动**：每当你打出此牌后，该牌腾挪至随机区域（覆盖连击默认回原位的口径）

#### 暮蛉

- `Cost = 5`，身材：23 生命值上限，词条：伙伴，稀有度：蓝
- 入战时角色生命值上限 +23，当前生命值 +23
- 冻结一个敌方部位 1 回合
- 突袭：暂未定义，先不进入第一版实现
- **被动**：当触发暮气时，使一张中毒卡牌效果 +1
  - "触发暮气"指暮气状态生效
  - "中毒卡牌"指效果里包含施加中毒的卡牌
  - 随机范围是手牌、抽牌堆、弃牌堆
  - 如果该牌有多个中毒相关效果，则全部中毒层数 +1

#### 暮色引虫灯

- 首先是一张卡牌
- 身材：1 耐久 / 3 容量
- 1 耐久 = 战斗中可打出一次，打完进消耗区
- 3 容量 = 增加背包上限 3
- 占用手牌区域，相当于正常卡牌
- 任务完成后升级这张卡牌

## §5 手牌区域

### 区域结构

```
[左手区] [左手牌] [双手区] [右手牌] [右手区]
```

- 左手牌左边为左手区
- 右手牌右边为右手区
- 左手牌与右手牌之间为双手区
- 每个区域容量暂时没有上限

### 区域判定

- 两张锚点都在手牌区时：左手牌左侧 = 左手区，中间 = 双手区，右手牌右侧 = 右手区
- 只有一张锚点在手牌区时：锚点左侧 = 左手区，锚点右侧 = Zone None，双手区不存在
- 两张锚点都不在手牌区时：所有普通卡牌 Zone = None
- 锚点本身 Zone 始终为 None

### 腾挪

- 腾挪表示重新放置当前手牌中的卡牌，使其进入不同手牌区域或在同一区域内改变位置。
- 腾挪范围默认是当前手牌中的普通卡牌（第一阶段默认不选择左手牌和右手牌）。
- 腾挪到目标区域时，插入目标区域内的随机位置。
- 如果随机目标区域等于当前区域，仍然会发生区域内重新放置。
- "从双手区腾挪到其他区域"：目标排除双手区，只能是左手区或右手区。
- "左方没有卡牌"指左手区没有牌（不是相邻位置为空）。

### 双手区失效

- 左手牌或右手牌离开手牌区时，双手区立刻失效。
- 原双手区中的牌仍保留在手牌中，但不再属于任何区域（Zone = None）。
- 腾挪可用区域缩减为仅 Left（锚点左侧）。
- 如果左右手牌都不在手牌区，所有普通卡牌 Zone = None，腾挪不可用。

### 手牌队列生成

- 回合开始固定从抽牌堆抽取 5 张普通卡牌。
- **左右手牌都不在手牌区**：先形成预备队列，再将左手牌和右手牌插入（两者之间至少一张普通卡牌）。
- **左右手牌都在手牌区**：不移动已有卡牌位置，新抽卡随机插入当前手牌区。双手区中被保留的卡牌保持原有相对位置。
- **只有一张锚点在手牌区**：按"都不在"的规则重新生成完整结构。

### 手牌上限

- 普通卡牌手牌上限为 10（不计算左手牌和右手牌）。
- 算上左右手牌后，最终手牌队列上限为 12。
- 超过上限的普通卡牌移动到弃牌区。

## §6 敌人与部位

### 敌人结构

一个敌人由多个部位组成。每个部位拥有：

- HP
- 当前意图（Intent）
- 当前先机（CurrentInitiative）
- 状态（Status）
- 部位顺序

### 部位破坏

- 部位 HP 归零后进入破坏态。
- 被破坏部位不再拥有意图和先机值。
- 被破坏部位不再参与先机扣减、意图刷新和行动结算。
- 不再作为普通目标被选择（除非卡牌明确允许）。

### 敌人击倒

以蛇为例：

- 蛇有头、身体、尾巴三个部位。
- 蛇头 HP 归零后触发头被破坏，同时触发敌人被击倒事件。
- 敌人不会因此直接死亡。全部部位被破坏后才算战斗胜利。

### 击倒事件与左右手选择

- 敌人被击倒时，提示玩家使用当前手牌中的左手牌/右手牌处理击倒事件。
- 如果已打出左手牌，只能使用右手牌。
- 如果左右手都不在手牌中，给默认奖励。
- 左手/右手在击倒事件中的选择会触发不同变化。

### 先机与完美释放

- 先机是敌人部位的行动倒计时。
- 玩家打出非迅捷卡牌后，所有存活部位当前先机减少该牌 `RuntimeCost`。
- 如果部位先机归零或低于零，该部位按固定顺序行动，然后刷新意图和先机。
- **完美释放判定**：出牌前记录所有存活部位的 CurrentInitiative。若 CardCost == Part.CurrentInitiative，则该 Part 命中 PerfectRelease。随后若卡牌不具备迅捷，统一扣减所有存活部位 CurrentInitiative。
- 某些卡牌可以在"区域条件 + 完美释放条件"同时满足时，让本次打出不减少敌方部位先机（不实现为提前给卡牌添加"迅捷"关键词）。

### 抵抗

- 先机命中时触发抵抗判定（先于完美释放）。
- 卡牌效果数值 vs 敌人意图数值进行比较。
- 如果卡牌抵抗值 > 意图抵抗值，该部位进入晕厥状态。
- 晕厥以层数模型记录，每次行动消耗 1 层。

### 部位行动规则

- 多个部位同时先机归零时，按部位顺序依次行动。
- 每个部位的每个意图自带先机值。
- 部位执行意图后，刷新到新意图，当前先机设为新意图的先机值。
- 部位在玩家回合内因先机归零行动后，玩家结束回合时仍会再次行动。

## §7 背包与构筑

### 背包

- 背包是战斗外永久卡牌池。
- 背包有容量上限，容量可以被提升。
- 背包里的牌默认不进入战斗牌组。
- 玩家战斗开始前从背包中选择一部分卡牌组成战斗卡组。

### 入战属性

- 如果一张卡被带入战斗并提供"生命值上限"，进入战斗时立刻增加角色生命值上限和当前生命值。
- 战斗中临时获得的提供"生命值上限"的卡牌也立刻生效。

### 战斗中从背包获取卡牌

- 后续可能有卡牌从背包中抽取卡牌。
- 没有特殊说明时，战斗中从背包抽来的牌，战斗结束后进入背包。

### 战斗结束回流

- 战斗结束后，当前战斗卡组中的所有卡牌都会进入背包。
- 敌人掉落牌是永久获得，也会在战斗结束后随卡组进入背包。
- 掉落卡进入背包会占用背包容量。
- 战斗失败代表本局游戏结束，不保留本场掉落。

### 非初始牌库

"非初始牌库"指除了当前角色初始手牌以外的其他卡牌池。后续可以包含其他角色对应卡牌，尽量设计成通用卡牌。

## §8 探索与 Run

### 长期方向

区域探索式 Run，而不是固定路线节点。

当前设想：

- 游戏开始后，玩家被载入一个大区域（类似《超时空方舟》的地图）。
- 可以自由探索，战斗之间不再通过固定路线节点前进。
- 区域内会有区域 Boss。

### 区域内容

- 普通战斗
- 精英战斗
- 区域 Boss
- 商店
- 事件
- 休息点
- 成长或卡牌管理点

探索部分应服务于卡牌构筑和战斗准备，不应削弱战斗作为核心玩法的地位。

## §9 美术方向

### 战斗画面

- 敌人部位需要有明确视觉分区。
- 意图和先机应靠近对应部位显示。
- 手牌位于画面下方，保留左手、双手、右手的空间感。
- 打出左手牌或右手牌时，手牌结构变化需要有清晰反馈。

### 氛围方向

当前卡牌示例包含昆虫、暮色、毒、冻结、暮气等意象。美术可以向自然、微光、昆虫、腐殖、潮湿洞穴和黄昏生态靠拢。

## §10 状态与效果

### 中毒

- 可叠加层数模型。
- 敌人有多个部位时，每个部位可以各自拥有中毒。玩家本体也可以拥有中毒。
- **触发时机**：玩家每打出一张牌后 + 敌方部位每行动一次后，对敌我双方各结算一次当前中毒层数伤害。
- 中毒伤害穿透护盾，直接扣除生命值。
- 层数不因结算而减少（持续存在直到被治疗或其他效果移除）。
- 被治疗时，移除治疗效果 10% 的中毒层数（向下取整）。

### 减速

- 基础控制类型。
- 使敌人当前意图延迟倒计时（增加当前先机值）。
- 施加给玩家时：玩家回合开始时使每张卡牌费用临时增加，回合结束时清除。
- "x 对应对象个数，y 代表程度"——对 2 个目标施加 3 减速表示每个目标先机 +3。

### 暮气

- 基础控制类型。
- 使敌人下一次意图延迟倒计时到来，生效后减少一半层数（向下取整）。
- 施加给玩家时：玩家回合开始时使每张牌的费用上限增加。使用沾染暮气的卡牌后，该牌层数减半。
- 回合结束后，洗入牌库的暮气仍然存在。

### 冻结

- 基础控制类型。
- **施加给敌方部位时**：该部位下一次行动跳过当前意图（与晕厥共享"跳过 + 消耗 1 层"分支）。
- **施加给玩家时**（未实现）：玩家回合开始时使每张牌不可被打出。使用相邻牌时解除冻结状态。
- 玩家所打出的牌仍需遵守其费用小于等于敌人倒计时总和。

### 连击

- 使用此牌后可重复使用。
- 非特殊情况，该牌打出后回到原位置。
- 连击与手牌区域变化、左手/右手离开、双手区失效之间需要单独定义。

### 晕厥

- 由抵抗判定施加。
- 层数模型，每次该部位行动（无论执行意图还是因晕厥跳过意图）都消耗 1 层。
- 层数归零时晕厥状态移除。

## §11 设计原则

- 先验证战斗节奏，再扩展 Run 外层。
- 先保证规则可读，再追求复杂卡牌组合。
- Cost 是风险，不是资源。
- 手牌位置是策略，不只是 UI 排列。
- 敌人部位要提供不同威胁，而不只是多个血条。
- 所有长期系统都应服务于卡牌构筑、战斗准备和战斗中的判断压力。
