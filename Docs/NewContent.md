压力系统本质是战斗外的“血量”，血量与压力是一种**资源**与**回合控制**

血量系统属性：**当前生命值、额外生命值、生命值上限**

  

【当前生命值】：在战斗外：当前生命值不作为交互对象（即不存在扣血等临时负面）其等价于玩家生命值上限，在战斗内：是判断游戏失败的主要条件与交互对象

##### **② 压力系统：**

**定义：**

对玩家而言：压力系统是**负面状态**的集合，其总值达到 100（%） 则游戏失败，战外事件会判断（读取）此值，压力也会影响玩家影音体验

## 4.3 时间/昼夜循环系统

**设计前提：**

昼夜时间的引入从底层设计来说是给予玩家明确的“决策成本”与告知进度推进的阶段，但真正有趣的是对现实一天的一种抽象，其引入了早晨的规划，日间的冒险探索，黄昏的餐饮，夜间的栖宿或晚间探险直到日出这些明确的小目标，供玩家完成并产生代入感与反馈感，且昼夜补全了**生态**中所需要的生息，这也使得交互变得立体与还原

  

**定义：**

时间是一种收束（随时间而变得困难）且线性的**决策成本**与**回合控制**

  

**昼夜（一天）：**

时间昼夜循环，循环一次视为一天，一天由【清晨】【日间】【黄昏】【夜间】四个主要时段与【日出】一个特殊时段按顺序更替组成一天

  

**时段：**

一个时段由一个或多个**节点**组成（其时段内的节点并非固定，可被增减），每个时段也拥有三时态（开始-进行中-结束）且拥有对应事件，生态或卡牌会响应对应时段

  

|   |   |   |   |   |   |
|---|---|---|---|---|---|
||节点数量|开始时|进行中|结束|补充|
|清晨|2|触发【清晨规划】事件|-|-|此事件减少 1 节点|
|日间|6|-|完成主要流程与事件|-||
|黄昏|2|选择触发【野炊】事件|触发则做饭/不触发则视为一个正常节点|-||
|夜间|2|选择触发【露营】事件|触发则露营/不触发则视为夜间探险|一天结束/探险衔接黄昏，一天结束|触发露营则节点推进1 点并结束  <br>触发探险则时段节点 余量为 2|
|日出|1|新的一天开始|-|-|日出是新的一天开始，但算作上一天的后置收益，相当于多执行一个节点|
|||||||

  

**节点：**

节点是整体流程的最小组成部分，其静置分布于地图之上并通过**通道**相连（通道并非节点），节点的本质是一个**事件**

  

每个节点也拥有三时态，“交互行为（查看商店，与人交流等）”的开始视为节点的开始，除战斗外节点可多个并行，但节点的结束或流程推进一定是“完成了行为（购买完成，完成任务，完成事件，完成战斗等）”
