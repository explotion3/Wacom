# Bug Girl Character Design

> [!warning] 文档边界
> 本文是虫妹角色设计语境，不是当前实现规格、DataAsset 验收清单或自动化测试依据。卡牌字段、生成资产、Battle / Run / UI 行为的当前事实，请看下方领域文档。

> [!info] 当前事实入口
> 静态字段与生成内容见 [`WacomData.md`](../WacomData.md)、[`WacomDataAuthoring.md`](../WacomDataAuthoring.md) 和 [`WacomGameplayTags.md`](../WacomGameplayTags.md)；战斗效果见 [`WacomBattle.md`](../WacomBattle.md)；Run 初始持有区、背包、奖励和存档边界见 [`WacomRun.md`](../WacomRun.md)；表现层见 [`WacomUI.md`](../WacomUI.md) 和 [`WacomBattleUI.md`](../WacomBattleUI.md)。

本文保留虫妹的角色幻想、机制方向和早期卡牌意图。后续若策划给出正式虫妹卡牌设计，应以领域文档和 DataAsset 为准重写实现合同。

## 1. 角色定位

虫妹是一名以伙伴、腾挪、手牌区域和状态生态为核心的初始角色方向。

她的体验重点不是稳定支付资源，而是在战斗中不断调整手牌位置，利用左手区 / 双手区 / 右手区的差异，触发伙伴联动，并用中毒、暮气、减速、冻结等状态改变敌人行动节奏。

### 核心体验

- 用低 Cost 伙伴牌调整手牌位置和状态。
- 通过腾挪制造区域收益。
- 利用完美释放和等待机制控制敌人部位先机。
- 在合适时机打出高 Cost 牌，换取强控制或爆发。
- 通过击倒变化和专属成长牌扩展长期构筑。

## 2. 核心机制方向

### 伙伴

伙伴是虫妹卡组的主要词条方向。

伙伴牌不预设为可被敌人攻击的场上实体，而是通过卡牌词条参与联动。虫妹可以围绕手牌中、战斗内或已失去的伙伴数量建立收益。

GameplayTag 命名、可制作范围和验证口径不在本文维护；见 [`WacomGameplayTags.md`](../WacomGameplayTags.md) 和 [`WacomDataAuthoring.md`](../WacomDataAuthoring.md)。

### 腾挪

腾挪是虫妹的主要操作动词。

腾挪表示重新放置当前手牌中的卡牌，使其进入不同手牌区域，或在同一区域内改变位置。虫妹通过腾挪改变区域归属，从而触发左手区、双手区、右手区收益。

当前手牌区域、PlayCard、PerfectRelease 和目标校验的规则事实见 [`WacomBattle.md`](../WacomBattle.md)。

### 左手 / 右手

左手牌和右手牌是虫妹的核心牌方向。

它们既是角色固有牌，也是手牌区域锚点。左手偏防御、抽取和非初始牌库成长；右手偏伤害、伙伴代打和腾挪成长。

左 / 右手作为角色固有牌的当前字段、初始持有区和删除边界，不由本文判断；分别见 [`WacomData.md`](../WacomData.md) 和 [`WacomRun.md`](../WacomRun.md)。

### 手指互动

手指是通用玩家身体资源。虫妹的特殊方向在于：暮色引虫灯可以把手指损失转化为角色成长收益。

每根手指对应多少最大生命值、失去手指后左 / 右手如何变化，仍属于开放设计问题；见 [`Questions.md`](../Questions.md#questions-hand)。

### 状态生态

虫妹涉及以下状态方向：

- 中毒：主要持续伤害方向。
- 暮气：控制和触发方向。
- 减速：延迟敌人行动方向。
- 冻结：限制行动方向。

这些状态的当前规则、保留字段和待确认公式不在本文维护；见 [`WacomBattle.md`](../WacomBattle.md)、[`Roadmap.md`](../Roadmap.md#roadmap-battle-rules) 和 [`Questions.md`](../Questions.md#questions-status)。

## 3. 初始核心牌意图

### 左手

- ID：左手
- Cost：2
- 词条方向：手 / 武器 / 工具

设计效果：

- 完美释放：闪避敌人攻击意图。
- 如果左方没有卡牌，则从背包随机抽取一张牌，并使其获得迅捷。
- 当结束回合时，如果双手皆在手牌中，则保留其区间内的手牌。
- 当敌人击倒时，获取敌人奖励，并使一张非初始牌库的牌置入背包。

设计意图：

左手是虫妹的防御和资源侧核心。它鼓励玩家制造“左方没有卡牌”的空间条件，并通过完美释放规避敌人的攻击意图。

### 右手

- ID：右手
- Cost：2
- 词条方向：手 / 武器 / 工具

设计效果：

- 造成 8 伤害。
- 如果相邻右方有伙伴，则可以改为使用该伙伴，并使其减少 1 点费用后腾挪到左手。
- 当结束回合时，如果双手皆在手牌中，则保留其区间内的手牌。
- 当敌人击倒时，获取敌人奖励，并额外随机获得一张带有腾挪的卡牌。

设计意图：

右手是虫妹的攻击和伙伴调度侧核心。它让右侧相邻伙伴成为潜在的代打资源，并推动虫妹围绕相邻位置和腾挪构筑。

## 4. 初始伙伴牌意图

### 朝光暮蝶

- ID：朝光暮蝶
- Cost：0
- 身材方向：1 生命值上限
- 词条方向：伙伴
- 稀有度方向：白

设计效果：

- 随机腾挪 1 张我方卡牌。
- 施加等同于此卡费用上限的中毒。
- 处于左手区域时，完美释放使此卡获得迅捷。
- 处于右手区域时，通过此卡腾挪的卡牌减少 1 点费用上限，由本卡替代。

设计意图：

朝光暮蝶是虫妹最基础的腾挪和中毒牌。它通过区域差异体现虫妹的核心玩法：同一张牌在不同区域有不同价值。

### 拂晓飞蛾

- ID：拂晓飞蛾
- Cost：0
- 身材方向：1 生命值上限
- 词条方向：伙伴
- 稀有度方向：蓝

设计效果：

- 对一个敌方单位施加 1 减速。
- 每当你打出三张伙伴时，使此牌回到手中。

设计意图：

拂晓飞蛾是伙伴连锁奖励牌。它鼓励虫妹持续打出伙伴，并为长期回手循环提供基础。

### 赤腹工蚁

- ID：赤腹工蚁
- Cost：0
- 身材方向：1 生命值上限
- 词条方向：伙伴
- 稀有度方向：白

设计效果：

- 保留。
- 将双手区域的随机 1 张卡牌腾挪至其他区域。

设计意图：

赤腹工蚁是双手区调度牌。它用于打破双手区结构，把卡牌推向左手区或右手区以触发区域收益。

### 烁光蝶

- ID：烁光蝶
- Cost：1
- 身材方向：6 生命值上限
- 词条方向：伙伴 / 武器
- 稀有度方向：白

设计效果：

- 连击。
- 造成 7 伤害。
- 每当你打出此牌后，该牌腾挪至随机区域。

设计意图：

烁光蝶是虫妹的基础伤害和连击牌。它每次打出后都会重新进入随机区域，制造持续变化的手牌局面。

### 暮蛉

- ID：暮蛉
- Cost：5
- 身材方向：23 生命值上限
- 词条方向：伙伴
- 稀有度方向：蓝

设计效果：

- 突袭。
- 冻结一个敌方单位 1 回合。
- 当触发暮气时，使一张中毒卡牌效果 +1。

设计意图：

暮蛉是虫妹的高 Cost 控制牌。它提供冻结和中毒强化，是虫妹从低 Cost 调度转向高风险强效果的代表。

突袭、暮气触发点和中毒修正范围仍是设计问题，不在本文写成规则；见 [`Questions.md`](../Questions.md#questions-status)。

## 5. 专属成长牌方向

### 暮色引虫灯

- ID：暮色引虫灯
- Cost：6
- 身材方向：1 耐久 / 3 容量
- 词条方向：专属 / 工具 / 容器
- 稀有度方向：固有

设计效果：

- 造成 1 暮气，1 中毒。
- 使相邻的卡牌具有伙伴类型。
- 手牌中每拥有一张伙伴，此卡牌就额外释放一次。

长期任务方向：

- 获得 45 张伙伴后，使此卡牌费用上限减一。
- 每失去 10 张具有暮气、中毒、减速、冻结的伙伴，奖励此卡获得对应效果；如果已经拥有，则改为效果 +1。
- 喂食一根手指时，使此卡获得被动：当夜幕降临时，探寻一张伙伴并永久获得。
- 失去一半手指时，使此卡额外对另一个随机目标生效。

设计意图：

暮色引虫灯是虫妹的长期成长核心。它像角色专属容器或核心装备，负责把伙伴数量、状态生态、手指损失和永久成长连接起来。

当前耐久、容量、任务进度、永久成长和夜幕触发都不作为本文实现合同；字段方向见 [`WacomData.md`](../WacomData.md)，后续能力见 [`Roadmap.md`](../Roadmap.md#roadmap-battle-rules)，开放问题见 [`Questions.md`](../Questions.md#questions-hand)。

## 7. 待确认问题导航

这些问题仍是设计问题。本文只保留导航，不直接回答：

- “费用上限”和 `Runtime Cost` 的正式关系。
- 朝光暮蝶左手区效果应写作“获得迅捷”，还是“本次不减少敌人先机但仍可触发完美释放”。
- 右手“改为使用相邻右方伙伴”的目标选择、费用变化和卡牌去向。
- “敌方单位”在部位制敌人中是否等同于“敌方部位”。
- 拂晓飞蛾回手时，如果手牌已满如何处理。
- 烁光蝶连击与随机腾挪的结算顺序。
- 暮蛉的“中毒卡牌效果 +1”是否影响所有中毒数值，还是只影响一个主效果。
- 暮色引虫灯的任务进度是 Run 内记录，还是角色永久成长记录。
- 每根手指对应多少最大生命值。
- 每次失去手指时，左手牌 / 右手牌分别发生什么变化。
- 失去 5 个手指后，先失去左手牌还是右手牌。
- 失去左右手牌后，是否立即重算手牌区域结构。

问题收口后，应先同步 [`Questions.md`](../Questions.md)，再同步对应领域文档和 DataAsset 合同。
