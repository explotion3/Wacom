# First-Person HD-2D Card Variant

本文用于记录“单人第一人称 HD-2D 卡牌冒险”中有关战斗部分的方案。它不是当前主线规则文档，也不替代 `Battle_Rules.md / Card_Design_Guide.md / Combat_Data_Schema_v2.md`。当前用途是沉淀已确认设计、待确认问题和后续原型切片，方便判断是否在当前项目分支上验证。

## 设计定位

该方案保留“卡牌战斗 + Run 外层 + 数据驱动内容”的大方向，但核心战斗模型从当前项目的“三角色小队 + AP/EP + 单体敌人单位”改为：

- 一人冒险。
- 第一人称 HD-2D 表现。
- 玩家没有 AP / EP。
- 卡牌 `Cost` 不再是资源消耗，而是敌方部位先机扣减值。
- 敌人由多个部位组成，每个部位有自己的生命、意图和先机。
- 手牌具有空间结构，分为左手区、双手区、右手区。
- 左手牌 / 右手牌本身也是普通核心卡牌，可以被打出、删除或被事件影响。
- 战斗外存在背包，背包管理玩家永久卡牌池。


## 已确认战斗规则

### 回合结构

- 回合仍然存在。
- 玩家可以主动结束回合。
- 玩家回合开始抽 5 张卡牌。
- 手牌打空后不会自动结束回合，仍需要玩家主动结束。

### Cost 与先机

- 卡牌 `Cost` 表示打出该牌后减少敌方所有存活部位的当前先机值。
- 例如 `Cost = 2`，则所有敌方部位当前先机都减少 2。
- `Cost` 不消耗玩家 AP / EP。
- 伤害、治疗、状态等其他效果仍正常执行。
- 卡牌在战斗中可以获得临时 `Runtime Cost` 修正。
- 完美释放判断和先机扣减都使用当前战斗内的 `Runtime Cost`，不是基础 Cost。
- 例如某牌基础 `Cost = 3`，被降到 `Runtime Cost = 2`，则按 2 判断完美释放，也按 2 扣减敌方部位先机。

### 费用转移

- 一张卡的 Cost 可以被临时降低，降低值可以转移到另一张卡上。
- 当前战斗内生效。
- 可以叠加。
- 示例：被腾挪卡 `Cost = 3`，被降低 1 点 Cost；这 1 点转移给朝光暮蝶，使朝光暮蝶 `Cost 0 -> 1`。

### 迅捷

- 迅捷卡即使本身有 `Cost`，打出时也不减少敌方部位先机。
- 迅捷卡不触发完美释放。
- 迅捷卡仍能执行自身其他规则效果。

### 完美释放

- 如果打出的卡牌 `Cost` 正好等于某个敌方部位在出牌前的当前先机，则该部位触发该卡牌的完美释放效果。
- 如果多个部位同时满足条件，则多个部位都触发完美释放。
- 迅捷卡不触发完美释放。
- 推荐实现口径：

```text
出牌前记录所有存活部位的 CurrentInitiative。
若 CardCost == Part.CurrentInitiative，则该 Part 命中 PerfectRelease。
随后若卡牌不具备迅捷，统一扣减所有存活部位 CurrentInitiative。
```

- 某些卡牌可以在“区域条件 + 完美释放条件”同时满足时，让本次打出不减少敌方部位先机。
- 这类效果不应实现成提前给卡牌添加“迅捷”关键词，否则会和“迅捷不触发完美释放”冲突。

### 部位行动

- 多个部位同时先机归零时，按部位顺序依次行动。
- 每个部位的每个意图自带先机值。
- 部位执行意图后，会刷新到新意图，并把当前先机设为新意图的先机值。
- 部位在玩家回合内因先机归零行动后，玩家结束回合时该部位仍然会再次行动。
- 玩家主动结束回合时，所有仍存活且可行动的部位按顺序执行当前意图并刷新意图。

该规则会显著提高打高 Cost 卡的风险：玩家回合内被推进到 0 的部位会行动一次，结束回合时仍会按当前意图再行动一次。

## 手牌区域

### 区域结构

手牌被左右手核心牌切分为三个区域：

```text
[左手区] [左手牌] [双手区] [右手牌] [右手区]
```

- 左手牌左边为左手区。
- 右手牌右边为右手区。
- 左手牌与右手牌之间为双手区。
- 每个区域容量暂时没有上限。

### 左手牌 / 右手牌

- 左手牌 / 右手牌是每个角色初始自带的核心牌。
- 不同角色的左手牌 / 右手牌可以有不同效果和 Cost。
- 左手牌 / 右手牌本身是普通卡牌。
- 它们可以被打出。
- 它们可以被删除，例如构筑选择或事件强制删牌。
- 打出左手牌或右手牌后，该牌离开手牌并进入弃牌堆。
- 回合开始时，，抽到本回合抽牌数量 5。
- “抽到 5”指本回合一共抽到手牌 5 张，包含强制抽回的左手牌 / 右手牌和其他正常抽牌。
- 如果左手牌被永久删除，左手区永久消失，双手区也不存在。
- 如果右手牌被永久删除，右手区永久消失，双手区也不存在。
- 如果任一手牌被永久删除，手牌区域只保留仍存在手牌锚点对应的区域。

### 双手区失效

- 左手牌或右手牌被打出后，双手区立刻消失。
- 双手区中的牌不会移动到左手区或右手区。
- 这些牌仍保留在手牌中，但失去“双手区”相关效果。
- 其他卡牌所属区域会因为左手 / 右手离开而重新判定。
- UI 视觉上可以重排手牌，但逻辑上这些原双手区牌不再拥有双手区效果。

### “左方没有卡牌”

当前定义：

- “左方没有卡牌”指左手区没有牌。
- 不是指该牌左侧相邻位置为空，也不是整个手牌最左侧为空。

### 腾挪

- 腾挪表示重新放置当前手牌中的卡牌，使其进入不同手牌区域，或在同一区域内改变位置。
- 腾挪主要用于改变卡牌的左手区 / 双手区 / 右手区归属。
- “随机腾挪 1 张我方卡牌”的范围是当前手牌。
- 如果指定从双手区腾挪到其他区域，则“其他区域”排除双手区，目标为左手区或右手区。
- 腾挪到目标区域时，插入目标区域的随机位置。
- 如果随机目标区域等于当前区域，仍然会发生区域内重新放置。

## 背包与战斗牌组

### 背包

- 背包是战斗外永久卡牌池。
- 背包有容量上限，容量可以被提升。
- 背包里的牌默认不进入战斗牌组。
- 玩家战斗开始前从背包中选择一部分卡牌组成战斗卡组。
- 如果一张卡被带入战斗并提供“生命值上限”，进入战斗时立刻增加角色生命值上限，并使当前生命值同步增加相同数值。
- 如果战斗中临时获得一张提供“生命值上限”的卡牌，也立刻增加角色生命值上限，并使当前生命值同步增加相同数值。
- 如果战斗中获得卡牌导致手牌超过上限，超出的卡牌进入弃牌堆。
- 首版可以先不设置严格手牌上限；一旦设置上限，统一使用“超出进弃牌堆”口径。

### 战斗中从背包获取卡牌

- 后续可能有卡牌从背包中抽取卡牌。
- 后续也可能有卡牌把背包内容作为条件判定或数值计算来源。
- 没有特殊说明时，战斗中从背包抽来的牌，战斗结束后进入背包。

### 战斗结束回流

- 战斗结束后，当前战斗卡组中的所有卡牌都会进入背包。
- 敌人掉落牌是永久获得，也会在战斗结束后随卡组进入背包。
- 掉落卡进入背包会占用背包容量。
- 战斗失败代表本局游戏结束，不保留本场掉落。
- 只要卡牌进入战斗卡组并进入手牌，就视为进入战斗；该卡所有入战属性立即生效。

### 非初始牌库

“非初始牌库”指除了当前角色初始手牌以外的其他卡牌池。

- 后续可以包含其他角色对应卡牌。
- 这些卡牌尽量设计成通用卡牌。
- 特定角色使用时可以特别契合，但不应完全无法被其他角色使用。

## 敌人与部位

### 敌人结构

- 一个敌人由多个部位组成。
- 每个部位近似当前项目中的一个 enemy unit。
- 每个部位拥有：
  - HP
  - Intent
  - CurrentInitiative
  - Status
- 暂定没有 Break。

### 部位破坏

- 每个部位 HP 归零后，触发部位被破坏。
- 被破坏部位不再拥有意图和先机值。
- 被破坏部位不再参与先机扣减和行动结算。

### 敌人击倒

以蛇为例：

- 蛇有头、身体、尾巴三个部位。
- 蛇头 HP 归零后，触发头被破坏。
- 同时触发敌人被击倒事件。
- 敌人不会因此直接死亡。
- 全部部位被破坏后才算战斗胜利。

### 击倒事件与左右手选择

- 敌人被击倒时，会提示玩家使用当前手牌中的左手牌 / 右手牌处理击倒事件。
- 如果这回合玩家已经打出左手牌，那么击倒事件中只能使用仍在手牌中的右手牌。
- 如果左右手都不在手牌中，则给默认奖励。
- 左手 / 右手在击倒事件中的选择会触发不同变化。

## 掉落与奖励

### 部位掉落

- 部位被破坏或敌人被击倒后，可以掉落与部位相关的卡牌。
- 例如蛇头可能掉落“毒牙”，效果可以是“施加 2 中毒”。
- 掉落牌会立刻加入手牌，参与本场战斗循环。
- 若手牌满了，首版可先进入弃牌堆；更完整的溢出规则后续再定。
- 掉落卡不是本场临时牌，可以被带出战斗。

### 非初始牌奖励

某些变化会让玩家从非初始牌库中选择一张卡牌置入背包。

当前示例：

```text
变化：当敌人击倒时：获取敌人奖励，并使一张非初始牌库的牌置入背包。
```

## 状态与效果

### Effect Type

“伤害”先作为 `EffectType`，不是状态或关键词。

当前定义：

- 基础伤害类型。
- 按数值扣除生命值。
- 可被护盾抵挡。

### 状态归属

状态未来可以挂在：

- 玩家本体。
- 单张卡牌。
- 敌人整体。
- 敌人部位。
- 敌人意图。

后续根据卡牌需要继续补充归属类型。

敌人整体状态等价于同时影响该敌人的所有部位。实现时可以选择在敌人整体层记录状态，再由规则查询时投影到部位；不要在 UI 中复制一份状态当真相。

### 伙伴

- 伙伴属于卡牌词条或卡牌类别。
- 伙伴不会作为场上实体被攻击。
- 当前伙伴牌上的“生命值上限”表示该牌进入战斗时增加玩家生命值上限和当前生命值，不表示伙伴自身生命。

### 中毒

当前理解：

- 如果敌人有多个部位，每个部位可以各自拥有中毒。
- 玩家本体也可以拥有中毒。
- 中毒结算在玩家打出一张牌或敌人行动一次后，对敌我双方结算一次当前中毒层数伤害。
- 中毒可以穿透护盾。
- 每 1 层中毒约等于每回合稳定 8 点直伤。
- 被治疗时，移除治疗效果 10% 的中毒层数。

中毒具体结算公式、取整、触发时机和多部位归属还需要正式化。

### 减速

当前理解：

- 减速是基础控制类型。
- 使敌人当前意图延迟倒计时。
- 被施加给玩家时，玩家回合开始时使每张卡牌费用临时增加，回合结束时清除卡牌减速效果。

该状态需要和“Cost 作为先机扣减值”的新模型重新对齐。

### 暮气

当前理解：

- 暮气是基础控制类型。
- 使敌人下一次意图延迟倒计时到来，生效后减少一半层数。
- 被施加给玩家时，玩家回合开始时使每张牌的费用上限增加。
- 使用沾染暮气的卡牌后，该牌层数减半。
- 回合结束后，洗入牌库的暮气仍然存在。

需要进一步区分：暮气是挂在玩家、卡牌、敌人意图，还是多处都可挂。

### 冻结

当前理解：

- 冻结是基础控制类型。
- 使玩家下一次打出的牌不减少倒计时。
- 被施加给玩家时，玩家回合开始时使每张牌不可被打出。
- 使用相邻牌时解除冻结状态。
- 玩家所打出的牌仍需遵守其费用小于等于敌人倒计时总和。

冻结与迅捷、Cost、完美释放的关系需要单独定义。

### 连击

当前理解：

- 使用此牌后可重复使用。
- 非特殊情况，该牌打出后回到原位置。

连击与手牌区域变化、左手 / 右手离开、双手区失效之间需要单独定义。

## 特殊卡牌：暮色引虫灯

当前理解：

- 暮色引虫灯首先是一张卡牌。
- `身材：1 耐久 / 3 容量`
- 1 耐久表示这张牌可以在战斗中被打出一次。
- 3 容量表示它会增加背包上限 3。
- 可以被打出。
- 打出后进入弃牌堆。
- 因为只有 1 耐久，打完一次后会进入消耗区。
- 占用手牌区域，相当于正常卡牌。
- 任务完成后相当于升级这张卡牌。
- 如果在战斗中完成任务，则在战斗中将该牌替换为升级后的卡牌。

当前卡面中“牌中每拥有一张伙伴，此卡牌就额外释放一次”先按条件判断理解，不作为正式被动系统扩展。

## 初始卡牌规则记录

本节记录当前角色初始卡牌的已确认口径。此处只记录规则含义，不代表已经进入正式 `FinalData` schema。

### 朝光暮蝶

- `Cost = 0`
- 身材：`1 生命值上限`
- 词条：伙伴
- 这张卡被带入战斗时，角色生命值上限 +1，当前生命值也 +1。
- 如果战斗中获得这张卡，同样立刻使生命值上限 +1，当前生命值 +1。
- 随机腾挪 1 张我方卡牌：
  - 范围是当前手牌。
  - 用于让卡牌移动到不同手牌区域。
- 施加等于此卡当前 Cost 的中毒：
  - 目标先按指定敌方部位处理。
  - 若此卡通过费用转移从 `Cost 0` 变成 `Cost 1`，则按当前 `Runtime Cost = 1` 施加中毒。
- 左手区 + 完美释放：
  - 当此卡处于左手区，且本次满足完美释放条件时，本次打出不减少敌方部位先机。
  - 该效果不作为真正“迅捷”关键词提前授予。
- 右手区：
  - 通过此卡腾挪的卡牌 Cost -1。
  - 被减少的 1 点 Cost 转移到朝光暮蝶上。
  - 朝光暮蝶的 Cost 当前战斗内 +1。
  - 可叠加。

### 拂晓飞蛾

- `Cost = 0`
- 身材：`1 生命值上限`
- 词条：伙伴
- 稀有度：蓝
- 这张卡被带入战斗或战斗中获得时，角色生命值上限 +1，当前生命值 +1。
- 对一个敌方部位施加 1 减速。
- 被动：每当你在本场战斗内打出三张伙伴牌时，使此牌从所有非手牌区域回到手牌。
- “三张伙伴”是战斗内全局计数。
- 触发后计数清零。
- 如果手牌能容纳，则回到手牌；手牌满时的处理后续再定。

### 赤腹工蚁

- `Cost = 0`
- 身材：`1 生命值上限`
- 词条：伙伴
- 稀有度：白
- 这张卡被带入战斗或战斗中获得时，角色生命值上限 +1，当前生命值 +1。
- 保留：
  - 沿用当前项目语义，回合结束不弃掉。
- 将双手区域的随机 1 张卡牌腾挪至其他区域：
  - 其他区域排除双手区。
  - 目标为左手区或右手区。
  - 如果双手区不存在，则此牌不能打出。

### 烁光蝶

- `Cost = 1`
- 身材：`6 生命值上限`
- 词条：伙伴 / 武器
- 稀有度：白
- 这张卡被带入战斗或战斗中获得时，角色生命值上限 +6，当前生命值 +6。
- 连击：
  - 使用此牌后可重复使用。
  - 本卡“打出后腾挪至随机区域”会覆盖连击默认回到原位的口径。
- 造成 7 伤害：
  - 目标是当前选中的敌方部位。
- 被动：每当你打出此牌后，该牌腾挪至随机区域。
  - 每次重复使用后都触发。
  - 如果随机区域是当前区域，仍然会发生区域内重新放置。

### 暮蛉

- `Cost = 5`
- 身材：`23 生命值上限`
- 词条：伙伴
- 稀有度：蓝
- 这张卡被带入战斗或战斗中获得时，角色生命值上限 +23，当前生命值 +23。
- 突袭：
  - 暂未定义，先不进入第一版实现。
- 冻结一个敌方部位 1 回合。
- 被动：当触发暮气时，使一张中毒卡牌效果 +1。
  - “触发暮气”指暮气状态生效。
  - “中毒卡牌”指效果里包含施加中毒的卡牌。
  - 随机范围是手牌、抽牌堆、弃牌堆。
  - `效果 +1` 指中毒层数 +1。
  - 如果该牌有多个中毒相关效果，则全部中毒层数 +1。

## Run 外层方向

仍然需要 Run 系统，但可能不再是当前项目的路线节点式 Run。

当前设想：

- 游戏开始后，玩家被载入一个大区域。
- 大区域类似《超时空方舟》的地图，可以自由探索。
- 战斗之间不再通过固定路线节点前进。
- 区域内会有区域 Boss。
- 仍可能存在：
  - 商店
  - 事件
  - 休息
  - 成长系统待定

当前项目的 `FinalRun` 仍有复用价值，但后续可能需要从“节点路线推进”演进为“区域探索状态机”。

## 当前项目复用判断

### 高复用

- `FinalCore` 基础 ID / 类型。
- `FinalData` 的 DataAsset 与 DataRegistry 思路。
- `BattleCommand / BattleSnapshot / BattleEvent` 的协议方向。
- `FinalEditor` 的 Validator / Bootstrap / 自动化测试框架。
- `FinalApp` 的 UI 父类、RootLayout、Overlay 管理、WidgetClassSettings。

### 中等复用

- `FinalRun` 的奖励、商店、事件、成长候选。
- `FinalBattle` 的卡牌效果执行管线。
- 状态系统中的 AppliesTo / RuntimeModifiers / DOT 思路。
- Intent 的 DisplayName / PreviewText / IconId 分层。

### 低复用或需要重写

- 三角色队伍模型。
- AP / EP 资源系统。
- 当前 Enemy = 单个单位的模型。
- 当前 Break 主机制。
- 当前手牌只按 `HandIndex` 排列的模型。
- 当前敌人先机响应规则。
- 当前路线节点式 Run 作为唯一外层流程。

## 建议第一阶段原型切片

第一阶段只验证战斗核心，不做背包、自由探索和完整掉落。

目标：

1. 单玩家。
2. 一个敌人：蛇。
3. 蛇有头 / 身体 / 尾巴三个部位。
4. 每个部位有 HP / Intent / CurrentInitiative。
5. 玩家回合开始抽 5 张。
6. 手牌有左手 / 双手 / 右手区域。
7. 打牌 Cost 扣所有存活部位先机。
8. 完美释放按出牌前部位先机判断。
9. 多部位归零后按部位顺序行动。
10. 玩家结束回合时，所有存活且可行动部位依次行动；即使该部位本玩家回合内已经因先机归零行动过，结束回合仍会再次行动。
11. 部位 HP 归零后进入破坏态，不再有意图和先机。
12. 全部部位破坏后战斗胜利。

第一阶段暂不做：

- 背包抽取。
- 掉落卡带出。
- 任务卡升级。
- 自由探索 Run。
- 状态挂意图。
- 卡牌耐久 / 容量。
- 非初始牌库奖励。
- 完整 UI 美术。
