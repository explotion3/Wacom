# 卡牌系统扩展计划

> 本文完成后删除。每完成一项打 ✅ 标记。

---

## 一、新增 EffectType Handler

| # | EffectType | 做什么 | 状态 |
|---|---|---|---|
| 1 | `Effect.Draw` | 从抽牌堆抽 N 张到手牌 | ✅ |
| 2 | `Effect.Discard` | 弃掉手牌中 N 张（随机，不弃锚点） | ✅ |
| 3 | `Effect.Heal` | 恢复玩家 HP + 移除 10% 中毒层数 | ✅ |
| 4 | `Effect.ExhaustSelf` | 本卡打出后进消耗区 | ✅ |
| 5 | `Effect.GainKeyword` | 给目标卡临时添加关键词（MetaTag 指定） | ✅ |
| 6 | `Effect.RemoveStatus` | 移除目标的指定状态 N 层（MetaTag 指定） | ✅ |
| 7 | `Effect.ModifyInitiative` | 直接增加/减少某部位当前先机 | ✅ |
| 8 | `Effect.RecoverFromDiscard` | 从弃牌堆随机/指定回收 N 张到手牌 | 待做 |
| 9 | `Effect.CopyCard` | 复制一张手牌的临时副本 | 待做 |

## 六、执行顺序

**第一批 ✅（已完成）：**
- Effect.Draw / Discard / Heal / ExhaustSelf
- Magnitude.Source.HandCount / TargetStatusStacks
- Magnitude Modifier 机制

**第二批 ✅（已完成）：**
- Passive.Trigger.OnTurnStart / OnTurnEnd / OnDraw / OnDiscard（代码就位，调用点待接入）
- Effect.GainKeyword / RemoveStatus / ModifyInitiative

**第三批（低优先级，按需）：**
- Effect.RecoverFromDiscard / CopyCard
- Target.AllHandCards / Adjacent / RandomEnemyPart
- Magnitude.Source.DiscardCount / DestroyedPartCount
- Passive.Trigger.OnEnemyPartDestroyed / OnPlayerDamaged

---

## 备注

- Passive Trigger 的调用点接入（在 BattleTurnFlow / EndTurnResolver / DeckService 里加一行调用）等策划给出具体使用这些 trigger 的卡牌时再做，避免现在做时序决策后面要改
- `Effect.GainKeyword` / `Effect.RemoveStatus` 使用 `FEffectContext::MetaTag` 传递要操作的 Keyword/Status Tag
- `Magnitude.Source.TargetStatusStacks` 借用 `FCardEffect::TargetZone` 字段传递要查询的状态 Tag（对非 Shuffle 效果该字段无其他用途）
