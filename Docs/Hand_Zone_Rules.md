# Hand Zone Rules

本文定义第一阶段手牌区域规则。本文只描述手牌队列、左右手牌、区域判定、保留和腾挪，不重复完整战斗流程。

## 1. 核心概念

手牌不是普通线性列表，而是由左手牌和右手牌切分出的空间结构。

完整结构为：

```text
[左手区] [左手牌] [双手区] [右手牌] [右手区]
```

左手牌和右手牌是手牌区域锚点。普通卡牌的位置会根据它们相对左右手牌的位置，被判定为左手区、双手区或右手区。

## 2. 左手牌与右手牌

左手牌和右手牌是特殊卡牌。

它们具有以下规则：

- 它们是卡牌，可以被打出。
- 它们是手牌区域锚点。
- 它们自带保留效果。
- 它们不会进入抽牌堆、弃牌堆、消耗区或其他普通卡牌区域。
- 它们被打出后，本回合离开手牌，但不进入任何卡牌区域。
- 如果回合结束时仍在手牌区，它们会保留到下一回合。

## 3. 手牌队列生成

回合开始时，先从抽牌堆抽取 5 张普通卡牌。之后根据左右手牌是否仍在手牌区，生成本回合手牌队列。

### 左右手牌都不在手牌区

如果左手牌和右手牌都不在手牌区：

1. 将抽到的普通卡牌与已有手牌形成预备队列。
2. 将左手牌和右手牌插入预备队列。
3. 生成最终手牌队列。

左手牌和右手牌插入预备队列时，两张牌之间必须至少有一张普通卡牌。

### 左右手牌都在手牌区

如果左手牌和右手牌已经在手牌区：

1. 不移动手牌中已有卡牌的位置。
2. 本回合抽到的普通卡牌随机插入当前手牌区。
3. 生成最终手牌队列。

如果双手区中有被保留的普通卡牌，这些卡牌保持原有相对位置。

### 只有一张手牌锚点在手牌区

如果只有左手牌或只有右手牌在手牌区，按“左右手牌都不在手牌区”的规则重新生成完整左右手结构。

## 4. 手牌上限

手牌上限只计算普通卡牌，不计算左手牌和右手牌。

普通卡牌手牌上限为 10。算上左手牌和右手牌后，最终手牌队列上限为 12。

保留在手牌中的普通卡牌也计入普通卡牌手牌上限。

如果普通卡牌超过上限，超过上限的普通卡牌移动到弃牌区。左手牌和右手牌不因手牌上限进入弃牌区。

## 5. 区域判定

当左手牌和右手牌都在手牌区时，区域判定如下：

- 左手牌左侧的普通卡牌属于左手区。
- 左手牌与右手牌之间的普通卡牌属于双手区。
- 右手牌右侧的普通卡牌属于右手区。

区域判定按当前手牌队列实时计算。

> **实现说明**：代码按"两锚点在队列中的位置"切三段，不区分哪个是 LeftHandInstanceId 哪个是 RightHandInstanceId。即"位置较小的锚点左侧 = Left 区，中间 = Both 区，位置较大的锚点右侧 = Right 区"。第一阶段锚点不被腾挪，物理方向不会颠倒。后续若引入"锚点可被腾挪"规则，需要正式定义"左手 vs 右手"的物理方向语义。

## 6. 双手区失效

如果左手牌或右手牌离开手牌区，双手区立刻失效。

双手区失效后：

- 原双手区中的普通卡牌仍保留在手牌中。
- 这些卡牌不再满足双手区条件。
- 其他普通卡牌所属区域会根据当前手牌队列重新判定。
- UI 可以重排展示，但逻辑区域必须按当前手牌队列重新计算。

如果左右手牌都不在手牌区，第一阶段不提供双手区判定。

## 7. 保留

左手牌和右手牌自带保留。

普通卡牌只有拥有保留规则时，才会在回合结束时保留在手牌区。

虫妹的双手区可以保留手牌。第一阶段口径为：当回合结束时，左手牌和右手牌都仍在手牌区，双手区中的普通卡牌可以保留到下一回合。

被保留的普通卡牌在下回合生成手牌队列时保持原有相对位置。

保留牌如果被主动打出，仍按普通打出处理，进入弃牌区，除非卡牌文本另有说明。

## 8. 腾挪

腾挪表示重新放置当前手牌中的卡牌，使其进入不同手牌区域，或在同一区域内改变位置。

### 腾挪范围

没有特殊说明时，腾挪范围是当前手牌中的卡牌。

左手牌和右手牌是否可以被腾挪，需要由卡牌文本明确说明。第一阶段默认普通腾挪不选择左手牌和右手牌。

### 腾挪目标区域

腾挪可以指定目标区域：

- 左手区。
- 双手区。
- 右手区。

如果目标区域不存在，则该腾挪不能执行。

### 随机腾挪

随机腾挪表示在合法范围内随机选择卡牌或目标区域。

如果随机目标区域等于当前区域，仍然会发生区域内重新放置。

腾挪到目标区域时，插入目标区域内的随机位置。

### 从双手区腾挪到其他区域

如果效果指定“从双手区腾挪到其他区域”，则目标区域排除双手区，只能是左手区或右手区。

如果双手区不存在，或双手区没有合法卡牌，则该效果不能执行。

## 9. 区域效果

卡牌可以拥有区域效果。

区域效果根据卡牌当前所属区域判断：

- 左手区效果只在卡牌处于左手区时生效。
- 双手区效果只在卡牌处于双手区时生效。
- 右手区效果只在卡牌处于右手区时生效。

如果卡牌离开对应区域，区域效果不再生效。

区域效果的触发时机由卡牌文本或战斗规则指定。
