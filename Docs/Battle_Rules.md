# Battle Rules

本文定义第一阶段战斗原型的通用流程。本文按“战斗开始 -> 回合开始 -> 执行阶段 -> 回合结束 -> 战斗结束”的顺序描述，不重复 GDD、角色文档和卡牌文档中的设定内容。

## 1. 战斗阶段总览

一场战斗由以下阶段组成：

```text
敌人初始化
-> 起始阶段
-> 执行阶段
-> 结束阶段
-> 若战斗未结束，回到起始阶段
```

执行阶段中，玩家可以在以下操作中选择：

- 打牌。
- 等待。
- 结束回合。

任何阶段中，如果触发胜利或失败条件，则进入战斗结束流程。

## 2. 敌人初始化

战斗开始时先初始化敌人。

初始化内容包括：

- 生成敌人。
- 生成敌人的所有部位。
- 为每个部位设置 HP。
- 为每个部位设置初始意图。
- 为每个部位设置当前先机。
- 建立部位顺序。

第一阶段测试敌人使用蛇，部位顺序暂定为：

```text
头 -> 身体 -> 尾巴
```

部位顺序用于同时行动、同时破坏、同时触发事件时的结算排序。

## 3. 起始阶段

起始阶段是每个玩家回合开始时执行的阶段。

### 起始阶段流程

```text
起始阶段开始
-> 结算“战斗开始时”类效果
-> 结算“直到回合开始”类效果终止
-> 结算“回合开始时”类效果
-> 判断左手牌和右手牌是否在手牌区
-> 按左右手牌状态生成本回合手牌队列
-> 超出普通手牌上限的普通卡牌移至弃牌区
-> 完成手牌队列
-> 起始阶段结束
```

### 战斗开始时

战斗第一回合开始前，先结算“战斗开始时”类效果。

该类效果用于处理入战属性、初始状态、初始抽牌修正等内容。

### 直到回合开始

如果存在持续到“回合开始”的效果，在本阶段终止。

### 回合开始时

结算所有“回合开始时”类效果。

### 左右手牌

左手牌和右手牌是特殊卡牌。

它们不会进入抽牌堆、弃牌堆、消耗区或其他普通卡牌区域。左手牌或右手牌被打出后，本回合离开手牌，但不会进入任何卡牌区域。

左手牌和右手牌自带保留效果。如果回合结束时左手牌或右手牌仍在手牌区，它们会保留到下一回合。

### 手牌队列生成

回合开始抽牌时，先从抽牌堆抽取普通卡牌。之后根据左右手牌是否仍在手牌区，生成本回合手牌队列。

#### 左右手牌不在手牌区

如果左手牌和右手牌都不在手牌区，则先将抽到的普通卡牌与已有手牌形成预备队列，再将左手牌和右手牌插入预备队列，生成最终手牌队列。

左手牌和右手牌插入预备队列时，两张牌之间必须至少有一张普通卡牌。

#### 左右手牌在手牌区

如果左手牌和右手牌已经在手牌区，则不移动手牌中已有卡牌的位置。

本回合抽到的普通卡牌随机插入当前手牌区，生成最终手牌队列。

虫妹的双手区可以保留手牌。如果回合开始时左右手牌仍在手牌区，双手区中被保留的卡牌也保持原有相对位置。

#### 单张手牌锚点缺失

如果只有左手牌或只有右手牌在手牌区，第一阶段暂定按“左右手牌不在手牌区”的规则重新生成完整左右手结构。该情况后续需要单独正式化。

### 手牌上限

手牌上限只计算普通卡牌，不计算左手牌和右手牌。

普通卡牌手牌上限为 10。算上左手牌和右手牌后，最终手牌队列上限为 12。

如果普通卡牌超过上限，超出的普通卡牌移动到弃牌区。左手牌和右手牌不因手牌上限进入弃牌区。

## 4. 执行阶段

执行阶段是玩家进行战斗决策的阶段。

执行阶段开始后，先结算“结束阶段到等待阶段”之间的过渡效果，然后进入玩家操作选择。

玩家每次操作结束后，都需要检查战斗是否结束。若战斗未结束，则回到执行阶段操作选择。

## 5. 玩家操作：结束回合

玩家选择结束回合后，立即进入结束阶段。

结束回合本身不打出卡牌，不减少敌人先机，不触发完美释放。

## 6. 玩家操作：等待

等待用于主动推进敌人部位先机。

### 等待流程

```text
执行等待
-> 当前等待值 +1
-> 所有敌人部位当前先机减少当前等待值
-> 判断是否有部位先机小于或等于 0
-> 若有，按部位顺序执行敌人意图
-> 读敌人刷新意图与倒计时
-> 返回执行阶段
```

等待不打出卡牌，不触发完美释放。

等待值的准确递增时机需要确认。当前按流程图写作“先等待值 +1，再按当前等待值减少敌人先机”。

## 7. 玩家操作：打牌

打牌是玩家选择一张手牌并尝试使用的操作。

### 打牌流程总览

```text
选择卡牌
-> 判断是否结束回合
-> 判断是否等待
-> 执行卡牌阶段开始
-> 判断卡牌合法性
-> 判断费用是否满足特殊条件
-> 判断卡牌费用是否超出敌方所有部位先机总和
-> 判断卡牌目标类型与敌人单位数量关系
-> 目标枚举
-> 费用枚举
-> 执行卡牌效果
-> 判断敌人是否造成击倒事件
-> 判断敌人是否死亡
-> 判断敌人是否执行意图
-> 执行卡牌阶段结束
```

### 卡牌阶段开始

进入打牌流程后，先触发“执行卡牌阶段开始”。

该阶段用于结算打牌前触发、临时费用修正、目标修正、区域修正等效果。

### 合法性判断

卡牌必须通过合法性判断后才能继续结算。

合法性至少包括：

- 该卡是否在手牌中。
- 该卡是否可被当前玩家使用。
- 该卡是否被冻结或被其他状态禁止使用。
- 该卡是否满足区域条件。
- 该卡是否拥有合法目标。

如果合法性不通过，返回执行阶段，不消耗卡牌。

### 特殊条件

部分卡牌可以拥有特殊使用条件。

如果卡牌需要满足特殊条件，则在费用与目标选择前进行判断。

如果特殊条件不满足，返回执行阶段，不消耗卡牌。

### 费用判断

卡牌费用允许大于敌方所有存活部位当前先机总和，但会改变结算顺序。

```text
Enemy Initiative Sum = Sum(Living Enemy Parts CurrentInitiative)
```

如果 `Card Runtime Cost <= Enemy Initiative Sum`，按正常顺序结算卡牌。

如果 `Card Runtime Cost > Enemy Initiative Sum`，敌人先行动，再结算卡牌效果。

该规则用于表达高费用卡牌的风险：玩家可以强行使用高费用卡牌，但必须先承受敌人的行动。

### 目标类型与敌人单位数量

卡牌目标类型需要和敌人单位数量关系匹配。

目标枚举口径：

| 目标枚举 | 单体卡牌目标 | 非单体卡牌目标 |
| --- | --- | --- |
| 单数敌人单位 | 单单 | 非单单 |
| 复数敌人单位 | 单群 | 非单群 |

说明：

- “敌人单位”在第一阶段主要指敌人部位。
- 单数敌人单位表示当前只有一个可选敌方部位或单位。
- 复数敌人单位表示当前存在多个可选敌方部位或单位。
- 单体卡牌需要玩家选择一个具体目标。
- 非单体卡牌可以作用于多个目标或由规则自动选择目标。

目标枚举完成后，进入目标选择或自动目标确认。

### 费用枚举

目标确认后，进入费用枚举。

费用枚举用于确定本次打牌实际使用的费用值、费用变化、费用转移和是否推进敌人先机。

费用枚举结果至少需要包含：

- 本次 `Runtime Cost`。
- 本次 `Runtime Cost` 是否大于敌方所有存活部位当前先机总和。
- 是否推进敌人先机。
- 是否触发完美释放判断。
- 是否存在费用转移。

## 8. 卡牌效果结算

卡牌效果结算分为正常费用和超额费用两个分支。

### 正常费用

如果 `Card Runtime Cost <= Enemy Initiative Sum`，按以下顺序结算：

1. 记录所有存活敌方部位的出牌前当前先机。
2. 判断先机命中的部位。
3. 对先机命中的部位执行抵抗判定。
4. 执行卡牌主动效果。
5. 执行完美释放效果。
6. 若本次打牌推进先机，则减少敌方部位当前先机。
7. 执行卡牌离开手牌后的去向。
8. 检查敌人击倒、死亡和意图执行。

### 超额费用

如果 `Card Runtime Cost > Enemy Initiative Sum`，按以下顺序结算：

1. 记录所有存活敌方部位的出牌前当前先机。
2. 判断先机命中的部位。
3. 对先机命中的部位执行抵抗判定。
4. 敌方存活且可行动部位按部位顺序执行当前意图。
5. 敌方行动后刷新意图和当前先机。
6. 检查玩家是否失败。
7. 如果战斗未结束，执行卡牌主动效果。
8. 执行完美释放效果。
9. 若本次打牌推进先机，则减少敌方部位当前先机。
10. 执行卡牌离开手牌后的去向。
11. 检查敌人击倒、死亡和意图执行。

如卡牌文本指定特殊顺序，以卡牌文本为准，但必须明确覆盖点。

## 9. 先机命中、抵抗与完美释放

先机命中按出牌前的敌方部位当前先机判断。

如果卡牌 `Runtime Cost` 正好等于某个存活部位的出牌前当前先机，则该部位被本次出牌命中。

多个部位可以同时被命中。

### 抵抗

抵抗是先机命中时触发的通用效果。

当卡牌 `Runtime Cost` 正好等于敌方部位出牌前当前先机时，对该部位执行抵抗判定。抵抗会将卡牌上的某一个数值与该部位当前意图上的某一个数值进行比较。

如果敌人意图的对应数值更低，则该敌方部位进入晕厥状态。

第一版示例：

```text
卡牌效果：造成 7 点伤害
敌人意图：攻击，造成 5 点伤害
抵抗比较：7 > 5
结果：敌方部位进入晕厥状态
```

具体使用卡牌上的哪一个数值、敌人意图上的哪一个数值，后续由抵抗规则正式定义。

非攻击效果与非攻击意图也需要支持抵抗。后续会将不同类型效果和意图转换成可比较的抵抗数值。

### 完美释放

完美释放和抵抗使用同一个先机命中窗口。

抵抗判定先于完美释放结算。

如果卡牌拥有完美释放效果，则对命中的部位执行该卡牌的完美释放效果。

迅捷卡不触发完美释放。

如果本次打牌推进先机，则所有存活敌方部位当前先机减少该卡 `Runtime Cost`。

不推进先机不等同于迅捷。已经完成的完美释放判断不会因为后续“不推进先机”而取消。

## 10. 敌人击倒、死亡与意图

卡牌效果结算后，按以下顺序检查敌人状态：

1. 判断该敌人是否造成击倒事件。
2. 判断该敌人是否死亡。
3. 判断该敌人是否执行意图。

### 击倒事件

如果卡牌使敌人达到击倒条件，则触发敌人击倒事件。

第一阶段可以先记录击倒事件，不实现完整奖励分支。

### 死亡

如果敌方全部部位被破坏，则敌人死亡。

敌人死亡后，进入战斗结束判断。

### 执行意图

如果敌方部位当前先机小于或等于 0，则该部位需要执行意图。

多个部位需要执行意图时，按部位顺序依次执行。

部位执行意图后，刷新到下一个意图，并将当前先机设置为新意图的先机值。

## 11. 结束阶段

玩家结束回合后进入结束阶段。

### 结束阶段流程

```text
结束阶段开始
-> 结算“回合结束时”类效果
-> 结算“直到回合结束”类效果终止
-> 判断敌方全部或我方生命值归零
-> 敌人执行回合
-> 敌人按部位顺序行动
-> 判断玩家或敌人是否被击倒
-> 敌人刷新意图与倒计时
-> 判断敌人玩家是否全部被消灭
-> 若战斗未结束，回到起始阶段
```

### 回合结束时

结算所有“回合结束时”类效果。

### 直到回合结束

持续到“回合结束”的效果在此阶段终止。

### 敌人执行回合

所有存活且可行动的敌方部位按部位顺序执行当前意图。

即使某个部位已经在本玩家回合内因先机归零行动过，结束阶段仍会再次按当前意图行动。

### 敌人行动后

敌人行动后需要刷新意图与倒计时。

然后判断玩家和敌人是否被击倒或被消灭。

如果战斗未结束，则进入下一轮起始阶段。

## 12. 部位破坏

部位 HP 归零后进入破坏态。

破坏部位：

- 不再拥有可执行意图。
- 不再参与先机扣减。
- 不再因等待减少先机。
- 不再执行回合结束行动。
- 不再作为普通目标被选择，除非卡牌明确允许选择破坏部位。

全部部位破坏后，敌人死亡。

## 13. 战斗结束

战斗结束流程用于处理胜利、失败和离开战斗。

### 胜利

如果敌方全部被击败或死亡，则战斗胜利。

胜利后：

1. 结算战斗结束时效果。
2. 处理第一阶段测试返回。
3. 返回测试场景入口或战斗 Actor 附近。

### 失败

如果玩家生命值归零或低于零，则战斗失败。

失败后：

1. 结算战斗结束时效果。
2. 处理第一阶段测试返回。
3. 返回测试场景入口或战斗 Actor 附近。

### 同时胜利与失败

如果同一次结算中同时满足胜利和失败，第一阶段暂定优先判定胜利。

## 14. 第一阶段暂定项

以下内容需要后续确认：

- 等待值初始值。
- 等待值是先 +1 再扣先机，还是先扣先机再 +1。
- 等待值是否每回合重置。
- 左右手牌插入预备队列时的具体随机算法。
- 回合开始抽到的普通卡牌随机插入已有手牌时的具体随机算法。
- 只有一张左右手牌留在手牌区时，是否重新生成完整左右手结构。
- 普通卡牌超出上限时，哪些牌优先进入弃牌区。
- 超额费用分支中，是否仍按出牌前先机判断完美释放。
- 超额费用分支中，敌人行动后是否仍需要再次扣减新先机。
- “敌人单位”和“敌人部位”的正式关系。
- 击倒事件的正式触发条件。
- 击倒和死亡的判定顺序是否保持当前流程。
- 状态完整结算公式。
